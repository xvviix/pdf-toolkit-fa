# 📄 PDF Toolkit v12

### ابزار قدرتمند و کامل PDF — نسخهٔ فارسی

<br/>

> یک ابزار **مستقل و بدون وابستگی خارجی** برای کار با PDF:
> تقسیم، ادغام، تبدیل به تصویر، چرخش، فشرده‌سازی و استخراج متن —
> به‌همراه **تشخیص خودکار نام افراد با OCR** برای مدارک اسکن‌شده
> مثل گواهی‌ها، شناسنامه‌ها و فرم‌های اداری.

## ✨ امکانات

### 📑 عملیات اصلی

| بخش | امکانات |
|------|---------|
| ✂️ **تقسیم / استخراج** | سه حالت: تقسیم همهٔ صفحات به فایل‌های جدا • استخراج صفحات انتخابی • هر N صفحه یک فایل |
| 🔗 **ادغام** | ترکیب چند PDF به یک فایل، با جابه‌جایی برای تنظیم ترتیب |
| 🖼️ **PDF به تصاویر** | تبدیل صفحات به PNG / JPEG / WEBP با کیفیت قابل تنظیم (۷۲ تا ۶۰۰ DPI) |
| 📸 **تصاویر به PDF** | ساخت PDF از چند تصویر (با حفظ ترتیب) |
| 🛠️ **ابزارهای پیشرفته** | چرخش صفحات (۹۰/۱۸۰/۲۷۰/‎-۹۰) • فشرده‌سازی • استخراج متن به TXT |

### 🤖 تشخیص خودکار نام (OCR)

| ویژگی | توضیح |
|-------|-------|
| **خواندن نام افراد** | نام و نام خانوادگی از مدارک اسکن‌شده خوانده می‌شود و **نام فایل** همان نام فرد می‌شود |
| **فارسی + انگلیسی** | تشخیص خودکار برای هر دو زبان (مدل‌های فارسی از قبل آماده‌اند) |
| **💛 هایلایت زرد** | اگر صفحه چند نام دارد، فقط ناحیهٔ هایلایت‌شده (با رنگ زرد) خوانده می‌شود |
| **👁 پیش‌نمایش** | قبل از اجرا می‌بینید چه نام‌هایی تشخیص داده شده — بدون ساخت هیچ فایلی |
| **✅ اعتبارسنجی** | هر نام امتیاز ۰-۱۰۰ می‌گیرد؛ اسامی مشکوک با ⚠ و خراب با ✗ مشخص می‌شوند |
| **🔢 اسامی تکراری** | اگر دو نفر همنام باشند، خودکار «نام ۲»، «نام ۳»... اضافه می‌شود |

### 📊 گزارش و امنیت

- **گزارش نهایی** بعد از هر عملیات: تعداد فایل‌ها، جمع صفحات، سالم بودن هر فایل
- **بررسی سلامت** — فایل‌های خروجی دوباره باز می‌شوند تا مطمئن شویم درست ساخته شده‌اند
- **نوار پیشرفت واقعی** — درصد دقیق پیشرفت هر عملیات
- **پاک‌سازی نام فایل** — کاراکترهای غیرمجاز (`\ / : * ? " < > |`) خودکار حذف می‌شوند

## 🚀 شروع سریع

### 🪟 ویندوز — ساده‌ترین راه

فقط روی **`run.bat` دوبار کلیک کنید.** این فایل به‌صورت خودکار:

1. ✅ پایتون را بررسی می‌کند (اگر نصب نباشد، راهنمایی نشان می‌دهد)
2. ✅ کتابخانه‌های اصلی سبک را نصب می‌کند (فقط بار اول)
3. ✅ می‌پرسد آیا OCR (حدود ۱ گیگابایت، اختیاری) نصب شود
4. ✅ برنامه را اجرا می‌کند

### 🐧 لینوکس / مک

```bash
# ۱. نصب وابستگی‌های اصلی (سبک)
pip install -r requirements.txt

# ۲. اختیاری — OCR برای «تشخیص خودکار (OCR)» (حدود ۱ گیگابایت)
pip install -r requirements-ocr.txt

# ۳. اجرای برنامه
python pdf_toolkit_v12.py
```

### 📦 نصب دستی (اختیاری)

```bash
# با محیط مجازی (پیشنهادی)
python -m venv venv
source venv/bin/activate    # لینوکس/مک
venv\Scripts\activate       # ویندوز
pip install -r requirements.txt        # هسته اصلی فقط
pip install -r requirements-ocr.txt    # اختیاری — OCR (~۱ گیگابایت)

# اجرا
python pdf_toolkit_v12.py
```

## 🤖 تشخیص خودکار نام (OCR)

### چطور کار می‌کند؟

```
PDF اسکن‌شده (گواهی، فرم، مدرک)
        │
        ▼
[۱] هر صفحه به تصویر تبدیل می‌شود
        │
        ▼
[۲] موتور OCR متن را می‌خواند
        │
        ▼
[۳] «نام» و «نام خانوادگی» پیدا می‌شود
        │
        ▼
[۴] نام فایل = نام کامل فرد
  «سهراب زارعی.pdf»
```

### مثال واقعی

یک گواهی فوت با فیلدهای «نام: سهراب» و «نام خانوادگی: زارعی»:

```
📄 سهراب زارعی.pdf
📄 سمنبر کشاورزی.pdf
📄 مرضیه زارع نژاد.pdf
📄 مهدی زرین خو.pdf
```

### 💡 وقتی صفحه چند نام دارد

1. فایل PDF را در Adobe Acrobat، Microsoft Edge یا هر نمایشگر PDF باز کنید
2. نام موردنظر را با ابزار **هایلایت (Highlight)** با رنگ **زرد** هایلایت کنید
3. فایل را ذخیره کنید (Ctrl+S)
4. برنامه فقط همان ناحیهٔ هایلایت‌شده را می‌خواند

> اگر هیچ هایلایتی نباشد، برنامه کل صفحه را می‌خواند.

### 👁 پیش‌نمایش قبل از اجرا

دکمهٔ «پیش‌نمایش اسامی» را بزنید تا ببینید OCR چه نام‌هایی تشخیص داده:

```
✓ سند.pdf • صفحه 1  ←  سهراب زارعی (100٪)
⚠ سند.pdf • صفحه 2  ←  سهراب ي؛ زارعي (70٪) — علائم: ؛
✗ سند.pdf • صفحه 3  ←  (تشخیص داده نشد)
```

## 📖 راهنمای استفاده

### گام ۱ — افزودن فایل‌ها

- **＋ افزودن PDF** — انتخاب چند فایل
- **📁 افزودن پوشه** — همهٔ PDF های یک پوشه
- فایل‌ها در لیست نمایش داده می‌شوند

### گام ۲ — انتخاب عملیات

| تب | چه کاری انجام می‌دهد |
|----|----------------------|
| ✂️ تقسیم/استخراج | حالت تقسیم + محدوده صفحات (مثلاً `1-5,8`) + نوع نام‌گذاری |
| 🔗 ادغام | ترتیب فایل‌ها را با ↑↓ تنظیم کنید + نام فایل خروجی |
| 🖼️ PDF به تصاویر | DPI، فرمت (PNG/JPEG/WEBP) و محدوده صفحات |
| 📸 تصاویر به PDF | افزودن تصاویر + نام فایل خروجی |
| 🛠 ابزارهای پیشرفته | زاویهٔ چرخش، کیفیت فشرده‌سازی، محدودهٔ استخراج متن |

### گام ۳ — نام‌گذاری فایل‌های خروجی

| حالت | توضیح |
|------|-------|
| **دستی (الگو)** | مثلاً `{name}_p{page}` → `سند_p1.pdf` |
| **تشخیص خودکار (OCR)** | نام فرد از روی مدرک خوانده می‌شود → `سهراب زارعی.pdf` |

### گام ۴ — اجرا

دکمهٔ **«▶ اجرای عملیات»** را بزنید. بعد از اتمام، **گزارش نهایی** نمایش داده می‌شود.

## 🛠️ رفع اشکال

| مشکل | راه‌حل |
|------|--------|
| برنامه باز نمی‌شود | `run.bat` را دوباره اجرا کنید تا پیام خطا را ببینید |
| خطای «پایتون پیدا نشد» | پایتون 3.10 تا 3.13 را از python.org نصب کنید و گزینهٔ «Add to PATH» را تیک بزنید |
| نصب روی پایتون 3.14 خطا می‌دهد | paddlepaddle برای 3.14 ویل ندارد — پایتون 3.12 یا 3.13 نصب کنید |
| تشخیص خودکار کار نمی‌کند | مطمئن شوید `requirements-ocr.txt` را نصب کرده‌اید (OCR اختیاری است) |
| نصب OCR ناموفق است | پکیج OCR حدود ۱ گیگابایت است — فضای دیسک و اینترنت را بررسی کنید یا از پایتون 3.12/3.13 استفاده کنید |
| اسامی به‌هم‌ریخته است | صفحه را بهتر اسکن کنید یا نام موردنظر را زرد هایلایت کنید |
| نصب کتابخانه خطا داد | اینترنت را چک کنید و `run.bat` را دوباره بزنید |
| فایل خروجی باز نمی‌شود | گزارش نهایی را بررسی کنید — اگر «سالم» نیست، دوباره عملیات را اجرا کنید |

## ❓ سوالات متداول

**س: آیا برای مدل‌های OCR اینترنت لازم است؟**
خیر — مدل‌ها در پوشهٔ `.paddlex` از قبل آماده شده‌اند.

**س: پایتون 3.13 دارم، چکار کنم؟**
برنامه باز می‌شود ولی OCR کار نمی‌کند. پایتون 3.12 نصب کنید (دقیقاً 3.12، نه بالاتر).

**س: صفحه‌ام چند نام دارد، کدام را می‌خواند؟**
اگر هایلایت زرد بگذارید، همان را می‌خواند. وگرنه اولین «نام + نام خانوادگی» صفحه.

**س: فایل‌های خروجی کجا ذخیره می‌شوند؟**
در پوشه‌ای که در «پوشه خروجی» انتخاب کرده‌اید (پیش‌فرض: `PDF_Toolkit_Output`).

**س: آیا فارسی و انگلیسی هر دو پشتیبانی می‌شود؟**
بله — رابط کاربری فارسی است و OCR هر دو زبان فارسی و انگلیسی را می‌خواند.
