## ✨ امکانات

| بخش | توضیح |
|------|-------|
| ✂️ **تقسیم / استخراج** | تقسیم همه صفحات، استخراج صفحات انتخابی، یا هر N صفحه یک فایل |
| 🔗 **ادغام** | ترکیب چند PDF به یک فایل با ترتیب دلخواه |
| 🖼️ **PDF به تصاویر** | تبدیل صفحات به PNG / JPEG / WEBP با کیفیت دلخواه (DPI) |
| 📸 **تصاویر به PDF** | ساخت PDF از چند تصویر |
| 🛠️ **ابزارهای پیشرفته** | چرخش صفحات، فشرده‌سازی و استخراج متن به TXT |
| 🤖 **تشخیص خودکار نام (OCR)** | خواندن «نام و نام خانوادگی» از مدارک اسکن‌شده و استفاده به‌عنوان نام فایل |
| 💛 **هایلایت زرد** | اگر صفحه چند نام دارد، فقط نام هایلایت‌شده را می‌خواند |
| ✅ **اعتبارسنجی اسامی** | امتیازدهی و هشدار برای اسامی مشکوک استخراج‌شده |
| 📊 **گزارش نهایی** | خلاصهٔ عملیات + بررسی سالم بودن فایل‌های خروجی |

## 🚀 شروع سریع

**روی ویندوز — فقط کافی است روی `run.bat` دوبار کلیک کنید.**

این فایل به‌صورت خودکار:
1. پایتون را بررسی می‌کند
2. کتابخانه‌های لازم را نصب می‌کند (فقط بار اول)
3. برنامه را اجرا می‌کند

**روی لینوکس / مک:**

```bash
pip install -r requirements.txt
python pdf_toolkit_v12.py
```

## 🖥️ پیش‌نیاز

- پایتون 3.8 تا 3.12 (3.12 توصیه می‌شود)
- اتصال اینترنت در اولین اجرا (برای دانلود مدل‌های OCR)

## 💡 نکته: وقتی صفحه چند نام دارد

اگر یک صفحه از PDF چند «نام و نام خانوادگی» داشته باشد:

1. فایل را در Adobe Acrobat، Microsoft Edge یا هر نمایشگر PDF باز کنید
2. نام موردنظر را با ابزار **هایلایت (Highlight)** با رنگ **زرد** هایلایت کنید
3. فایل را ذخیره کنید (Ctrl+S)
4. برنامه فقط همان نام هایلایت‌شده را برای نام فایل استفاده می‌کند

> اگر هیچ هایلایتی نباشد، برنامه کل صفحه را می‌خواند.
